# FinGraph-Sentinel

## Systemic Risk Intelligence Using Financial Graphs

FinGraph-Sentinel is a research project that analyzes financial networks to identify systemic risk, simulate shock propagation, and develop early-warning signals for financial stress.

### Key Components

- Dynamic financial network construction
- Systemic risk analysis
- Shock propagation simulation
- Regime-aware risk evaluation
- Machine learning-based early-warning detection
- Interactive Streamlit dashboard

### Technologies

Python, Pandas, NumPy, NetworkX, Scikit-Learn, PyTorch, PyTorch Geometric, Matplotlib, and Streamlit.

### Project Status

Research and experimental development. Results are exploratory and subject to limitations involving dataset size, validation windows, and event frequency.
